We'll use the Epley formula:
\[
\text{e1RM}=\text{Weight}\times\left(1+\frac{\text{Reps}}{30}\right)
\]

For example, if you bench 185 lb for 5 reps:
\[
185\times(1+5/30)=215.83\text{ lb}
\]
